# Dearly

Dearly is a digital gifting platform for creating thoughtful, personalized gifts that recipients can unwrap in a browser.

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

The current product direction and technical agreements are documented in [`Dearly_Project_Discussion_and_Agreements.md`](./Dearly_Project_Discussion_and_Agreements.md).
